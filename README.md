# Valleyball Demo
 
Welcome to the Valleyball Alpha! This is an early technical test of the movement and strike mechanics.
 
## Controls

| Action | Keyboard | Gamepad (Xbox / PS) |
|---|---|---|
| **Move** | WASD | Left Stick |
| **Camera** | Mouse Drag (Left Click) | Right Stick |
| **Jump** | Space | A / Cross (South Button) |
| **Sprint** | Shift (Hold) | L2 / LT (Left Trigger) |
| **Slide** | C (Hold) | R2 / RT (Right Trigger) |
| **Dive** | Q | X / Square (West Button) |
| **Volley / Kick** | E | B / Circle (East Button) |
| **Spike** | R | Y / Triangle (North Button) |
| **Reset Ball** | B | Start / Options |

## Objective
Try to score a goal by getting the balls through the ring! There are three different balls in the arena to test out. Have fun and let me know what you think!
